# SSH Live Manager 🖥️

A lightweight, Linux-based desktop application to monitor network devices, track live IPs, and manage SSH connections through a clean GUI. 

## Features
* **Live Status Monitoring:** Automatically pings saved IP addresses to display real-time ONLINE/OFFLINE status.
* **Quick SSH Access:** One-click terminal launcher for instant SSH connections.
* **Default IP Configurations:** Comes pre-configured with a default list of team nodes and devices.
* **Native Desktop Integration:** Creates a fully integrated Ubuntu application shortcut with a custom vector icon.

## Installation

Run the following commands in your Linux terminal to clone the repository and install the desktop application:

```bash
git clone [https://github.com/ShiyadChathoth/ip-monitor.git](https://github.com/ShiyadChathoth/ip-monitor.git)
cd ip-monitor
chmod +x install.sh
./install.sh
